## Building now: [martocci.dev](https://martocci.dev)

A heritage site for the Martocci family, who came to America from Laurenzana in Basilicata.

- **Public history:** the surname and its spellings, the homeland, and the Italian emigration from 1806 to 1965, with a source and a confidence label on every claim.
- **Private family tree:** each Ancestry export is matched against the tree on weighted criteria (Italian/English names, dates, places, relatives). Strong matches merge, uncertain ones go to a review queue, and every change can be undone.
- **Family Historian:** a Claude-powered chat with tools over the live tree.
- **Stack:** Cloudflare Workers, D1 and R2, Cloudflare Access, the Claude API.
